# Multimodal AI Bootcamp

这是我的 12 周多模态视觉智能课程仓库。Week 1 的目标是建立一个可以从空环境复现的研究工程。

## Week 1 工具

`image_info.py` 用于读取单张图片，并输出：

- 图片路径；
- 宽度；
- 高度；
- 文件格式。

## 支持环境

- Ubuntu Linux
- Python 3.10–3.12
- CPU 即可
- 不需要 GPU
