# Week 1 项目计划

## 1. 当前问题

多模态文档研究会处理大量图片和扫描页面。在正式调用模型前，
需要确认输入文件是否存在、是否能够被正确读取，以及图片尺寸是否符合预期。

## 2. 项目范围

本项目实现一个命令行图片信息检查工具，输入单张图片路径，输出：

- 文件路径；
- 图片宽度；
- 图片高度；
- 图片格式。

项目同时提供可复现的 Python 环境、测试、运行说明和原始运行证据。

## 3. 非目标

本周暂不实现：

- 批量目录扫描；
- PDF 页数统计；
- OCR 文字识别；
- 图片压缩或格式转换；
- 图形界面；
- GPU 或深度学习模型调用。

## 4. 初步成功标准

满足以下条件即认为 Week 1 工具达到目标：

1. `--help` 能显示使用方法；
2. 能正确读取测试图片的宽度、高度和格式；
3. 文件不存在时给出可理解的错误信息；
4. 非图片文件输入时给出可理解的错误信息；
5. 自动化测试全部通过；
6. 从全新 clone 和空虚拟环境中能够按 README 复现；
7. 另一位同学能够根据 README 完成运行。
