# Dataset Card：Week07 Synthetic Document Benchmark v1.0

## 用途与规模

固定小测试集用于评价 Week06 Docling Pipeline 的内容恢复与结构保留，为后续比较建立基线。27 份独立单页 PDF：test 24（digital、scan、table 各8），dev 3（各1）。没有训练集；Week08 若需训练，须另准备训练/验证数据。测试集不用于训练、Prompt 调整、超参数或模型选择。

这是本仓库新制作的虚构教学数据，不是 OmniDocBench 子集，也不是来自真实业务的抽样。24 个页面对应24个样例，但共享少量生成模板，不能视为24个独立现实场景。

## 来源、生成与版本

由 Codex 在用户授权的课程实验中编排制作，版本1.0，日期2026-11-11，语言中文与ASCII编号/数值。程序为 `scripts/prepare_dataset.py`，使用 Week05 的通用文字/表格绘制函数，不复用 Week05 PDF 内容或结果。

- digital：虚构实验记录，4页单栏、4页双栏，按左栏读完再读右栏定义顺序。
- scan：虚构设备记录，只有图像、没有可提取文字层；分为4档DPI/模糊/旋转组合，每档2页。档位同时改变多个条件，只做分布切片，不能解释为某个单因素的因果作用。
- table：含5行6列、跨行/跨列单元格的物资表，各页数值和编号不同，表格模板相同。
- dev：每类型1页，不与test共享PDF字节或编号，但共享生成模板。当前不执行任何调参，也没有训练；未来需要更强的跨模板留出集。

参考答案在 `references/` 中，含生成时指定的文字块、阅读顺序、表格网格及合并范围，先于模型输出生成。是机器生成规格参考，不冒称人工标注；用户视觉核验尚待完成。没有删掉低分样例或按照解析结果修订答案。

## 许可与隐私

新制作的虚构文字、数值和参考规格沿用本仓库教学材料 CC0-1.0 的许可声明；不包含真实姓名、联系方式、业务或机密信息。使用的 Droid 和 DejaVu 字体许可与字体子集嵌入说明见 [Week05 字体许可目录](../week05/samples/licenses/) 和 [来源说明](../week05/samples/README.md)。不将字体许可改写为 CC0；未复制完整字体文件。模型来源、许可和模型文件哈希沿用 [Week06 模型准备记录](../week06/evidence/model-preparation.json)。无外部付费 API 调用或私人文档上传。

## 划分与冻结

`data/test-manifest.json`、`data/dev-manifest.json` 逐项保存相对路径、输入与参考 SHA-256、类型、布局、档位与split；`data/freeze.json` 固定上述文件和评价/解析配置、生成/评价源码。无随机抽样，seed=null；不宣称模型逐字节确定性。

冻结后生成器拒绝重建。校验程序逐项复核哈希，并检查test与dev、Week05已有PDF的精确重复。SHA-256只能排除完全相同的文件，不能证明无语义、模板或模型预训练数据污染。自制页面降低外部原页直接重叠风险，但仍无法证明模型没见过类似内容/版式。

## 偏差、已知限制与不适用场景

中文短页、固定字体、清晰表格、少量模板，缺少真实长文档、手写、真实扫描、数学公式、多语言和复杂跨页表格。类型是互斥实验分组，真实数字PDF可以同时包含复杂表格。样例按类型均衡不代表现实分布；分数不能外推为生产准确率或与官方排行榜比较。

主指标是本地规范化字符编辑相似度，不是完整OCR、TEDS或官方OmniDocBench得分；忽略标点、空格和大小写，亦不能验证标题层级或公式。辅助表格指标十分严格，阅读顺序只检查指定标记对；需结合原页和失败案例理解。

## 维护与未来使用

v1 输入与指标固定。本轮仅运行既有baseline，检查失败供诊断，不基于test修改配置。后续改进先在dev选择；如人工发现参考错误，保留v1结果，建立v1.1及更正说明，并让所有方法在新版本上重评。不要覆盖冻结文件来“修正”分数。公开数据和结果时保留本卡与AI使用说明。
