# Docling 运行证据目录

当前无本周实验结果。后续由本人执行解析入口，每轮创建独立目录，原始结果不覆盖、不手改。

计划记录：

- 原始 Markdown/JSON，按文档 ID 分开保存。
- 完整运行命令、配置及其快照、代码 commit 与工作区状态、源代码哈希。
- 输入、人工预期、质量规则的快照或清单及哈希。
- Python、Docling 与实际依赖版本，OCR 引擎、语言、CPU/线程、模型来源与 revision 或文件哈希。
- 开始时间（Asia/Shanghai）、各文档耗时、退出码和错误日志。首次下载耗时与转换耗时分开记录；缓存状态如实标明。
- 机械质量检查结果与空白人工核对表；人工评价在实际观察后归档。

单份失败时保留原因与已生成产物，继续处理其他输入，整轮返回非零退出码；具体规则在实现入口时核验。失败目录同样属于证据。模型权重与虚拟环境留在本机，代码、配置、小型原始结果和报告按来源许可保存到 GitHub。
