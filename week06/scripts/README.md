# 程序准备位置

程序已由 Codex 编写，工程验证与环境状态见 ../evidence/；本人亲自运行学习实验。

程序职责：校验输入和配置 → 调用 Docling → 分别导出 Markdown/JSON → 保存元数据、日志与失败状态 → 进行机械检查。程序不自动填入本人的内容判断，也不修改原始结果使其符合预期。

| 文件 | 作用 |
| --- | --- |
| run_pipeline.py | 本人的实验入口；按固定配置处理三份 PDF，保留原始产物与待核验表 |
| prepare_models.py | Codex 的准备入口；下载固定来源模型并记录文件哈希，不解析 PDF |
| verify_setup.py | Codex 的环境检查入口；验证模型能在 CPU 上离线加载，不调用文档转换 |
| test_pipeline.py | 工程测试；检查输入变化、失败/超时处理及导出格式，不执行真实 PDF 解析 |
