# 自主答辩练习

以下是AI准备的练习答案，本人理解后用自己的话回答。

| 问题 | 回答主线与证据 |
| --- | --- |
| 项目解决什么问题？ | 研究CPU上混合PDF解析是否保留OCR，以及内容指标能否代表结构质量；不是宣称发明新模型。 |
| 如何保证比较公平？ | 同24页、原Week07评分、相同模型/解析选项，仅OCR开关不同；历史baseline计时与本轮负载不能构成严格测速对照。 |
| 为什么选择保留OCR？ | 扫描切片相似度从0.950549降到0，数字PDF相似度不变；选择与输入类型有关。 |
| 文字分高为什么表格失败？ | 文字编辑相似度不核对网格和合并单元格，strict结构指标独立；打开对应原页/参考/JSON确认。 |
| adapter全对为何不用生产？ | 只有12条共享模板合成文本、单seed，币种与模板相关；未验证真实PDF、独立新分布或业务风险。 |
| Week07和Week09为何不在同一test排名？ | 中文PDF结构任务与英文文本字段任务不兼容；保留课程字面项差距，不捏造端到端验证。 |
| 你复现了什么？ | 当前VM及新clone重算原始输出与核对归档；没有在新机器下载模型后重训，也没有同学独立复现的反馈。 |
| r4参数减半为何内存不减半？ | 总内存包含基座、框架、激活和optimizer，单次进程RSS还有波动；无全参/重复测量不能归因。 |
| 哪部分是AI做的？ | AI编写、执行、检索、重算、组织报告；本人要核验原页/原文、记录理解、实际耗时并自主作答。 |
| 如果再做四周，最先做什么？ | 先补人工核验，再在dev打破模板/币种相关；另锁final-test，不用已经查看的test反复调参。 |
