# 指标与选择理由｜Week 5

课程依据：[Document AI 专题](https://multimodal-vision-ai.github.io/multimodal-document-ai-learning-center/learning/07_Doc_AI/)。下表由 Codex 根据任务范围整理，是本轮评价说明；本人在复盘中选定物理可读性，理由已记录在文末；不把收尾选择追写成运行前的个人决策。

## 当前评价单位与方法

三份文档各一页，观察单位是固定的标题、段落先后关系、公式上下标、表头/单元格关系和关键字段。沿用运行前定义的 11 项人工检查，不把它们当作 11 个独立文档样本。

| 关注点 | 本轮判定 | 选择理由（Codex 整理） |
| --- | --- | --- |
| 线性阅读顺序 | D3：左栏两段完成后是否才进入右栏 | -layout 改变布局保留方式，顺序是否符合目标必须单独检查；视觉分栏更清楚不能替代它 |
| 关键字段归属 | T2：是否能对应纸张—第二季度—数量12/金额60 | 数字都存在也可能季度/列名错配；该项直接检验关系，不能只数文字或数字 |
| 物理可读性 | P1/P2：改善、无改善、变差，并给出新旧原文位置 | 记录人能否借助对齐辨认分栏和表头，补充但不替换结构检查 |
| 结构表达与能力范围 | D2/D4/T1 与 S1–S3 分别记录结构未表达/工具不支持 | 不把无 OCR 或无结构表示误判为 OCR 模型错字；同因检查不重复计为独立故障 |

本轮只报告类别计数和逐项证据，不给总体准确率。主观察项/补充项在新运行前已定义于 layout.json 的快照；本页仅解释既有选择，不在运行后改分母、阈值或评分规则。

## 专题中的常见指标与本轮边界

| 任务 | 可进一步学习的指标 | 本轮是否计算及原因 |
| --- | --- | --- |
| OCR | CER、WER、Edit Distance | 未计算；没有全页逐字参考，也未运行 OCR 模型 |
| Layout analysis | IoU、mAP、F1 | 未计算；没有工具区域框/类型输出及完整人工框标注 |
| Table recognition | TEDS、cell F1 | 未计算；没有 HTML 树/单元格范围预测及对应完整参考 |
| Document parsing | 文本、表格、公式和阅读顺序分项指标 | 当前用有限核心人工检查观察，未建立完整解析评测集 |
| Document VQA | Accuracy、ANLS、人工 groundedness | 未计算；没有执行本周 VQA 模型问答 |
| Information extraction | Precision、Recall、F1 | 未计算；没有执行按 schema 抽取字段的系统 |

这些名字用于认识不同任务的评价对象，不声称已掌握全部指标实现。退出码、文件存在与字节数是运行状态证据，不代替内容质量指标。Week 7 再依据固定测试集、参考标注和实际输出设计可计算指标。

## 本人的选择理由

本人选择“物理可读性”，理由为“加上排版后，就不只是孤零零的文字，更方便阅读”。这与运行前已列的 P1/P2 对应，是本人当前复盘最看重的改善；没有更改原先 11 项检查或事后添加通过条件。

Codex 补充：物理可读性可以是本轮局部改善的证据，但不能单独证明线性阅读顺序、表格合并范围或公式关系正确；本人对 D3、T1、D4 的逐项观察仍保留。首次输出也仍含正确内容，不能把“不方便阅读”扩大为所有内容无意义。
